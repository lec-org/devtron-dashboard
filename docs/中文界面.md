# 中文界面维护

本分支默认使用简体中文。界面标签、帮助、空态、校验和操作提示统一由 `src/i18n/zh-CN.json` 维护；Devtron、Kubernetes、Helm、GitOps 等产品名和专业术语保留原文。日期与相对时间使用中文语言包。

`scripts/chinese-copy-plugin.mjs` 在 Vite 开发和正式构建中处理应用及 `@devtron-labs/devtron-fe-common-lib` 的显示文案。静态文案在构建时替换，动态标签在显示位置查词典；路由、状态枚举、判断条件、请求字段、资源名称、代码和命令保持原值。翻译在本地完成，不调用在线服务。

新增页面、更新上游或升级共享组件后，执行 `yarn check:zh`。缺失项会显示原文及文件位置，补充译文后重新检查。专业术语应明确登记原文，不用空字符串跳过。检查也会验证转换后的语法及协议边界。

登录页使用中文产品介绍，替代上游含英文截图的宣传面板。用户输入、终端输出、构建日志、YAML 和第三方诊断不作为界面文案翻译。

后端的中文错误由 Devtron 服务的 `internal/i18n/zh-CN.json` 维护。显示使用 `userMessage`，排障使用原始 `internalMessage`；前端不要将后者直接显示为操作提示。
